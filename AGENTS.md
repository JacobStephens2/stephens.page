## Agent skills

### Issue tracker

Issues and specs live as GitHub Issues, managed with the `gh` CLI. Before reading or publishing issues, follow `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles map 1:1 to label strings: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

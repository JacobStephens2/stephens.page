Current Focus: thirdshift

Thirdshift takes GitHub issues through implementation, standards and spec reviews, CI checks, and bounded repair loops to pull requests. Its Rust engine coordinates six coding-agent harnesses and dependency-aware parallel tickets in separate Git worktrees. Failed runs preserve their work for continuation, and merging is explicitly configured.

I test the factory's behavior as well as building it. My 183-session code-review evaluation compares a second model family with fresh sessions of the same model, with the controls, results, and limitations published together.
